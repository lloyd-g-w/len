# Len — Roadmap to GoodNotes / Notewise parity

Status: ✅ done · 🚧 in progress · ⬜ planned

## Ink & pens
- ✅ Pressure-sensitive pen, highlighter, stroke eraser, undo/redo
- ⬜ Pen types: ballpoint, fountain, brush, pencil (textured), marker
- ⬜ Pen customisation: pressure curve, smoothing/stabiliser, tip taper, opacity
- ⬜ Full colour picker (HSV + hex), saved favourite colours, per-tool presets
- ⬜ Highlighter renders behind ink; hold to straighten
- ⬜ Pixel (partial) eraser, eraser size, "erase highlighter only"

## Editing tools
- ⬜ Lasso: select, move, resize, rotate, recolour, delete, cut/copy/paste, duplicate
- ⬜ Shapes: draw-and-hold to snap (line, arrow, rectangle, ellipse, triangle, polygon)
- ⬜ Text boxes (font, size, colour)
- ⬜ Images (insert, move, resize, crop later)
- ⬜ Laser pointer
- ⬜ Gestures: two-finger tap undo, three-finger tap redo; S Pen button action setting

## Pages & documents
- ⬜ Templates: Cornell, narrow/college ruled, music staff, planner; paper colours
- ⬜ Page sizes (A4, A5, Letter, square) and orientation
- ⬜ Page overview: thumbnails, reorder, duplicate, delete, insert
- ⬜ Bookmarks
- ⬜ Continuous vertical scrolling of pages
- ⬜ PDF import & annotate; export notebook to PDF / PNG

## Library
- ⬜ Folders (nested), move to folder
- ⬜ Search, sort (date / name), favourites, grid/list views
- ⬜ Live cover thumbnails, more covers
- ⬜ Trash with restore, duplicate notebook

## App
- ⬜ Theme mode (system/light/dark), accent colour
- ⬜ Redesigned editor chrome, focus mode, customisable toolbar
- ⬜ Open-notebook tabs

## Sync
- ✅ Self-hosted LWW record sync
- ⬜ Blob sync (images, PDFs)
